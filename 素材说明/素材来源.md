# 素材来源

角色：CrossPet 动漫角色素材包，来源 https://github.com/lokicorvus/crosspet ，本项目使用已收集的透明 WebP 动作。具体署名及 CC BY-NC-SA 4.0 许可见角色原始许可。

背景：根据本次确认的蟹堡王布局，使用内置 imagegen 重绘为空场景；提示词另存于本目录。人物由页面独立绘制，不存在背景中预先画好的员工。

界面图标、员工帽、米饭/报纸/餐盘道具：本页面自有 SVG/CSS 图形。原先的 SVG 鱼居民已被替换为 36 位来自 TiantianTitan/codex-anime-pets 的 2D Q 版动漫角色，详见 36位居民来源.md；员工三人继续使用 CrossPet 原素材。
