# 蟹堡王 · AI 办公餐厅

把文本任务变成一份会被送到桌边的餐品。老板 **GPT**、接单员 **克劳德**、厨师 **大肥鱼**，一起接待 36 位 Q 版居民。

三个角色共用你自己的 DeepSeek API；角色名字与形象不代表切换真实模型。

## 功能

- 居民进门 → 克劳德接单 → 客人入座 → 窗口交代厨房 → 大肥鱼处理 → 窗口交餐 → 克劳德送到桌边。
- 180 组原始角色动作：GPT 62、克劳德 57、大肥鱼 61；右键点播，左键聊天，包含角色名片。
- GPT 安排克劳德擦桌、拖地、迎客；克劳德指挥大肥鱼煎汉堡、整理厨房、休息吃饭。
- 随机待机：老板数钱巡视，克劳德读报碎碎念，大肥鱼吃米饭哼歌；新订单优先。
- 36 位动漫居民轮换，也可在图鉴指定下一位来访。
- 桌椅、门、前台和墙体有碰撞边界，人物沿通道绕行，走到座位旁送餐。
- 串行排队、取消和重试、任务历史、复制结果、继续追问，以及真实账户余额查询。

## 运行

需要 **Node.js 22 或更高版本**，无需安装第三方依赖。

```sh
git clone https://github.com/shn0713/krusty-krab-ai-office.git
cd krusty-krab-ai-office
node server.mjs
```

打开 <http://127.0.0.1:4318/>。不配置密钥也能点击“演示一单”查看本地流程。

真实任务：把 `.env.example` 复制为 `.env`，填入自己的 DeepSeek 密钥，然后：

```sh
node --env-file=.env server.mjs
```

也可设置 `DEEPSEEK_API_KEY` 环境变量，或者将密钥放进 `runtime/deepseek-key.txt`。`.env`、`runtime/`、日志均被 Git 忽略。

Windows 可双击 `启动餐厅.cmd`，使用此入口时请预先设置环境变量，或将密钥放进上述 runtime 文件。双击 `停止餐厅.cmd` 停止服务。服务仅监听本机。

## 操作

| 操作 | 用途 |
| --- | --- |
| 输入任务，按 Enter | 下单；Shift + Enter 换行 |
| 左键角色 | 单独聊天 |
| 右键角色 | 名片、动作、互动、指挥菜单 |
| 触屏长按 / Shift + F10 | 打开角色动作菜单 |
| 居民图鉴 | 查看居民，安排下一位来访 |
| 设置 | 速度、随机动作、空闲剧情、碰撞路线显示 |

随机动作、擦桌剧情、本地演示不调用模型。真实订单和单聊使用 API。任务历史只保存在浏览器，不随仓库上传。目前支持文本任务与对话，没有网页搜索、文件操作或邮件发送工具。
